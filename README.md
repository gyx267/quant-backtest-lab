# 量化回测与风险分析工具

一个面向 A 股/基金的个人学习项目：用 Python 做数据获取、技术指标、策略回测和风险分析。

## 为什么做
- 金融背景 + 编程兴趣
- 练习 pandas、数据清洗、回测
- 目标：跑通一个双均线策略的回测，输出夏普、最大回撤

## 功能（计划）
- [ ] 数据获取（akshare）
- [ ] 数据清洗与存储（SQLite）
- [ ] 技术指标（MA/RSI/MACD）
- [ ] 双均线策略回测
- [ ] 绩效指标（年化、夏普、最大回撤）
- [ ] 简单 Web 展示（FastAPI + ECharts）

## 技术栈
Python 3.11+、pandas、numpy、matplotlib、akshare、SQLite、FastAPI

## 目录
- `src/`：代码
- `data/`：本地数据（不入库）
- `notebooks/`：实验
